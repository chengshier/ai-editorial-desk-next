# Non-Goals

V1 明确不追求：

- 做一个“所有内容统一 0–100 分”的万能评分器。
- 以七个平台全部实时抓取作为产品价值证明。
- 自动发布所有 AI 生成内容。
- 用 DeepSeek Harness session 代替业务数据库。
- 用 WeKnora 代替 Subject/Evidence/Candidate/Publication 数据模型。
- 在 Harness Developer Preview 阶段维护大规模 upstream fork。
- 自动修改 rubric/prompt/policy 并直接上线。
- 把长视频“抓到了元数据”误称为“已经理解视频内容”。
