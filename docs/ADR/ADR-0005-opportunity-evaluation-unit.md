# ADR-0005 — Editorial Opportunity Is the Evaluation Unit

Status: **Accepted**  
Date: 2026-08-17

## Decision

Editorial Value Evaluation 与 CandidateV2 主要绑定 Editorial Opportunity，而不是裸 Subject 或 Legacy Event。

## Reason

人工基准表明，同一个 Subject 在不同 Angle、Theme、Audience Promise、Context 下可产生完全不同的编辑价值。评价 Subject 本身会丢失真正决定“做不做”的变量。

## Consequence

允许一个 Subject/Discovery 产生多个 Opportunity；历史 Opportunity 不因新 Angle 覆盖。Trend 仅作为 objective feature 输入之一。
